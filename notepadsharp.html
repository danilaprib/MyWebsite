Notepad# (reads Notepad Sharp)

Windows text editor with hotkeys for faster UI interaction and directory navigation and a built-in arithmetic expression parser

What is done for now

Directory navigation with either Directory text box or a file dialog

Hotkeys to swap (change focus) between UI elements

Creating new files, deleting files, writing and saving text

Simple arithmetic expression parser that allows you to insert results into text
(CANNOT HANDLE PARENTHESES YET)

Stack used and problems solved during development

WPF framework and XAML language for designing the user interface and C# for code-behind

File streams to open, modify and save text files

Arithmetic expression parser that creates a linked list from string expression with nodes for operators and numbers and solves it in 2 iterations:
1st being high precedence (multiplication and division)
and 2nd being low precedence (addition and subtraction)
