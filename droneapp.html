GroundDroneApp

Desktop application for controlling the drone remotely and getting readings from it and storing them in the database

What is done for now

Communication with the Arduino board using serial port (you can control 2 servos by pushing buttons in the UI)

RepeatButtons send commands to Arduino without any errors

Overall UI design

Stack used and problems solved during development

WPF framework and XAML language for designing the user interface and C# for code-behind

SerialPort class to instantiate serial port object to be able to send UTF-8 ASCII to Arduino board

Arduino code that uses Serial class to read the ASCII from the buffer and execute the corresponding commands based on what ASCII was received

You can control 2 servo motors (left-right and up-down) using arrow keys on your keyboard. Pressing and holding the key down rotates the servo motor, releasing the key stops the motor

To be implemented and reworked

New, more modern UI with multiple themes to select

More UI elements to control the camera, tracks, set the maximum speed and other components on the drone

Apache Cassandra database to get real-time reading from the sensors and store them for future debugging

Fully functional remote control not using USB wires

.exe installer for Windows

Bug fixing, add unit tests and documentation with explanations for users of how to work with it
