MusicPlayer

Music player with hotkeys for audio playback controls and navigating between directories

What is done for now

You can specify the directory to load audio files from by typing it in the text box at the top or opening a dialog window

Enumerating the audio files from the specified directory with data binding to show their names in the list

Creating new files, deleting files, writing and saving text

Simple arithmetic expression parser that allows you to insert results into text
(CANNOT HANDLE PARENTHESES YET)

Stack used and problems solved during development

WPF framework and XAML language for designing the user interface and C# for code-behind

File enumeration from the specified directory to get all the .mp3 files

Timer to show the current position on the song

MediaElement from WPF to load the audio file into and control left-right balance, rewind, etc.

To be implemented and reworked

New, more modern UI with multiple themes to select

More audio file formats than just .mp3

.exe installer for Windows

Bug fixing, add unit tests and documentation with explanations for users of how to work with it
